# Module Memory Bank

This directory contains the technical documentation for the module. Follow the structure below:

## Required Files
1. **project-brief.md**: Formalized requirements from description/master.md
2. **tech-stack.md**: Recommended tools and technologies for implementation
3. **system-architecture.md**: Module architecture and file structure
4. **implementation-plan.md**: Step-by-step development checklist
5. **progress.md**: Tracking of implementation progress

## Optional Files
- **feature-implementation.md**: For specific feature implementations
- **api-documentation.md**: API documentation if the module exposes interfaces
- **testing-strategy.md**: Testing approach and test cases
- **deployment-guide.md**: Deployment instructions

## Workflow
1. Start by creating `project-brief.md` based on `../description/master.md`
2. Develop `tech-stack.md` with technology recommendations
3. Design `system-architecture.md` with module structure
4. Create `implementation-plan.md` with atomic steps
5. Update `progress.md` as you work through the implementation plan
